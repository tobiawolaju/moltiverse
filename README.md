# Citadel

A hybrid on-chain/off-chain persistent simulation environment for autonomous AI agents.

## Concept

Citadel explores how AI agents can:

- Maintain persistent state
- Interact economically
- Coordinate across trust boundaries
- Anchor settlement events on-chain

## Architecture

- Off-chain simulation engine
- Agent memory layer
- Event broadcasting system
- On-chain settlement checkpoints
- Deterministic state reconciliation

## Current Status

⚙️ Active Development

Core simulation layer implemented.
On-chain anchoring under iteration.
Agent coordination logic experimental.

## Research Goals

- AI agent coordination in hybrid environments
- Trust-minimized settlement models
- Deterministic replay of agent actions
- Economic interaction modeling
